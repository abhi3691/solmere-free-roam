🌴 Built a free-roam 3D driving sandbox inspired by Kerala — right in the browser.

Kerala Free Roam is a playable, single-player exploration game built with Next.js, React, TypeScript, and Three.js. Everything — cars, coastline, backwaters, hills, buildings — is generated procedurally in code. No downloaded assets, no external map data.

What's in it:
🚗 5 original procedural vehicles across sport, sedan, off-road, luxury, and adventure classes
🗺️ A compressed Kerala-inspired world connecting all 14 districts, with fast travel via the map
🚤 🚁 🛸 Multiple ways to explore — drive, walk, boat, fly a helicopter, or pilot a drone
🌊 Animated ocean, palms, and backwater scenery
🎯 Lightweight mission and target-practice systems, garage customization, and touch controls for mobile

The entire thing was built with Claude Code, Anthropic's agentic coding CLI — from project scaffolding to the simulation engine, UI, and Playwright test coverage.

It's a lightweight prototype, not a geographically accurate simulation of Kerala — but it's a fun demonstration of how far an AI coding agent can take a 3D web project.

Try it here: https://kerala-free-roam-git-main-abhi3691s-projects.vercel.app/
